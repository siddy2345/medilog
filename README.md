# 💊 Medilog

> Simple, convenient medicine & supplement intake tracking.

I forgot how many magnesium tablets I'd already taken one day, went looking for an app to track it, and ended up building my own instead. That's how Medilog was born — a small, focused web app for keeping tabs on your daily medicine or supplement intake.

## ✨ Features

- 📋 Add any medicine or supplement you take
- 🎯 Set a daily intake goal per item
- ✅ Log your intake throughout the day
- 💾 Data persists locally in your browser — no account, no backend, no signup
- 🪶 Lightweight, fast, and distraction-free

## 🛠 Tech Stack

- [Angular](https://angular.dev/) — standalone components, signals
- [PrimeNG](https://primeng.dev/) — UI components
- Browser `localStorage` for persistence
